# 掘金 OpenIM 系列来源清单

本目录保存 OpenIM 源码深度解析系列文章的来源索引、元数据和我们自己的学习摘要。

## 边界

- 不保存第三方文章正文全文。
- 不保存页面原始 HTML、`mark_content` 或可还原正文的数据。
- 只保存 URL、标题、作者、发布时间、修改时间和自写摘要。
- 如果后续你本人拥有版权、已获得授权，或通过平台功能合法导出了文章文件，可以放入 `authorized-exports`，我再帮你整理、分章、建立索引和关联源码。

## 文件

- [sources.md](sources.md)：18 篇文章的来源表和学习用途。
- [metadata.json](metadata.json)：机器可读的来源元数据，不含正文。
- [authorized-exports/README.md](authorized-exports/README.md)：授权原文导入说明。
